AI Company Backup

A personal backup tool used by its owner to store encrypted backups in their own Google Drive. This is not a public backup service.

Files are compressed and encrypted locally with an age public key before upload. The private decryption key stays with the owner and is not sent to Google Drive or this website.

Google authorization uses only https://www.googleapis.com/auth/drive.file: the tool can manage the Drive files it creates or that are explicitly made available to it. It does not request access to all existing Drive files.

The tool checks uploaded backups and keeps the four latest verified copies. It runs locally on the owner's computer using rclone.

This website contains no backup data and accepts no file uploads or account registrations.
