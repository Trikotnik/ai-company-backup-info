Privacy policy

Effective date: 20 November 2026.

AI Company Backup is a personal, locally operated tool for backing up its owner's files to the owner's Google Drive. It is not offered as a hosted service to other users.

Google data and permissions

The tool requests only the Google Drive drive.file permission. It uses this permission to create a backup folder, upload encrypted backup archives and checksum records, verify their metadata or download them for integrity and restoration tests, and delete older backup files. It does not request general access to existing Google Drive files.

Encryption and storage

Backup content is encrypted locally before upload. Only the owner retains the private decryption key. Google Drive stores encrypted archives and non-secret checksum records. Google authorization credentials are handled by rclone and stored locally on the owner's computer, not on this website and not in the backup folder.

Use and sharing

Google user data is used solely to provide the personal backup and restore functionality described above. It is not sold, used for advertising, shared with data brokers, or used to develop or train artificial intelligence models. Data is transmitted to Google Drive at the owner's direction. No separate application server receives it.

AI Company Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The backup tool retains the four latest verified backup copies. The owner can stop the scheduled task, delete backup files in Google Drive, remove local authorization credentials, or revoke access in Google Account settings. Revoking authorization stops future access; it does not itself delete existing backups.

This website

This static site does not ask for credentials, collect backup content, or add analytics or tracking scripts. GitHub Pages hosts it and may process standard request information under GitHub's privacy statement.

Contact

Questions about this personal tool can be directed to its owner through the GitHub account hosting this website. Never send private keys, passwords, authorization tokens, or backup content.
